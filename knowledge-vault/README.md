# Knowledge Vault

This directory stores local-readable Markdown career notes. It is the human-readable layer of the CV Master knowledge system.

Postgres is the canonical source of truth for structured career facts. This vault mirrors those facts as editable Markdown files with stable frontmatter IDs that link back to database records.

## Directory Structure

- `profile.md` — user profile information
- `work/` — work experience records
- `projects/` — project records
- `education/` — education records
- `certifications/` — certification records
- `skills/` — skill records
- `stories/` — STAR stories and narrative career events
- `evidence/` — supporting evidence notes
