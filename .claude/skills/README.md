# CV Master Project Skills

Project-local development skills for the CV Master repository. These skills establish a consistent planning → building → verifying → shipping workflow.

These skills are **local to this repository only**. They are not installed globally.

## Skills Overview

| Order | Skill | When to Use |
|---|---|---|
| 01 | Blueprint First | Before starting any non-trivial task |
| 02 | Build Discipline | During implementation |
| 03 | Experience QA | After implementation, before handoff |
| 04 | Ship Handoff | Before committing and responding to user |

## Quick Start

Read [skill-index.md](./skill-index.md) to select the right skills for your task, then follow them in order.

For most implementation tasks, use all four in sequence: 01 → 02 → 03 → 04.
