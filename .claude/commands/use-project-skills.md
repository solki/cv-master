# Use Project Skills

Before starting a task in CV Master:

1. Read `.claude/skills/skill-index.md`.
2. Select the relevant skill files for your task type.
3. Follow the selected skills in order.
4. In the final handoff, state which skills were used.

## Default implementation workflow

For most code changes:

- `.claude/skills/01-blueprint-first.md` — plan before coding
- `.claude/skills/02-build-discipline.md` — implement with discipline
- `.claude/skills/03-experience-qa.md` — verify through tests and screenshots
- `.claude/skills/04-ship-handoff.md` — commit and summarize

## Priority

Project-local skills (`.claude/skills/`) take priority over global skills for this repository. Do not use globally installed development workflow skills for CV Master unless the user explicitly asks.
